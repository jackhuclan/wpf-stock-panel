# P0 过程记录

> 这份文档是 P0 阶段的**决策与验证记录**，不是功能介绍。功能与结构见 [`../README.md`](../../README.md) 与 [设计文档](./specs/2026-11-10-tsp-csharp-desktop-design.md)。
>
> 它为什么存在：P0 由 9 个任务、9 轮单任务复审、1 轮整分支复审、4 轮修复与 1 轮最终修复波构成，过程中控制者（AI）替所有者做了 **81 条编号裁决**。这些裁决若不落纸就等于**秘密决策**——所有者无从知道哪些判断需要推翻。本文把全部裁决连代价一并列出。

## 2. 怎么验证的

规模：**53 个测试**（`Tsp.Contracts.Tests` 6 ＋ `Tsp.Desktop.ViewModels.Tests` 47）、构建 **0 警告 0 错误**。

但有测试不等于验证过。这次过程里真正起作用的是**四类手段**：

1. **变异测试（贯穿全程，最有效）**。反复用"把实现改坏，看测试是否真的失败"来判定覆盖是否承重。它抓出了四个**存活变异**——即测试全绿而行为已错的地方：标题无断言、`Order` 值与顺序无断言、`InnerException` 未钉、以及 `{StaticResource}` 令牌引用（该变异存活全部 49 个测试）。
2. **独立复现而非采信自述**。复审者自行重算对比度、逐张打开截图核对像素、程序化比对两套主题的键集合、用 .NET 正则模拟重跑守卫的计数。
3. **实机运行**。验收不是"构建变绿"，而是跑起来用 UI Automation 逐项点击 + 逐像素判定（涨格红>0/绿=0，跌格反之）。失败路径靠**把 `Fixtures` 目录改名**验证，验完改回并核对。
4. **上游被下游纠正**。本阶段**五次**出现实现者或复审者用实证推翻上游结论，其中**两次推翻的是控制者自己的裁决**（见 §4 的 62→66、14→74）。这不是事故，是这套流程有效的证据。

## 3. 验证结论

最终整分支复审（最强模型，整分支 32 提交 diff）的判定：**Ready to merge = With fixes**，发现 1 Critical ＋ 3 Important ＋ 10 Minor。唯一一波修复后，scoped 复审判定：**全部 8 项 ADDRESSED，无新增 Critical/Important，Critical 确实关闭**——由两条独立证据支撑：VM 测试（同时钉住"异常不外逃"与"`ErrorMessage` 非空"两个失效模式），以及在修复后的真实 exe 上重跑原始崩溃场景（窗口存活、显示可读错误）。

## 5. 已知残留与后续阶段的必读项

### 必须在 P2 处理（**最重要的一条**）

- **Ruling 78：兜底分支的注释把 `TaskCanceledException` 列为"已被捕获"，但它继承自 `OperationCanceledException`，在上层就被捕获并上抛。** 因此 **HTTP 请求超时**（区别于用户主动取消）会逃出 `LoadAsync` 抵达 dispatcher——**正是 P0 刚关闭的那个进程死亡模式**。P0 不可达（夹具客户端、`CancellationToken.None`），但 **P2 一接 HTTP 就会踩上**。P2 需要为"超时 vs 取消"定一条明确策略。
- **Ruling 23**：`WatchlistItem.Instrument` 缺字段时会被注入 `null`，夹具写错会导致更深处的 `NullReferenceException`；边界校验属 P2。
- 接口未规定"取数失败"与"取消"同时发生时的优先级（实现先查目录再查 token）。

### 必须随 P1 计划下发

1. **视图分发缝不存在**——P0 只有一种页面、直接实例化 `PlaceholderPage`；P1 的 20 个页面需要 ViewLocator / `DataTemplate` 选择器。
2. **侧栏余量约 24 逻辑像素且无滚动条**——角标行与 8px 按钮间距都从这里支付，P1 添加任何东西都需先做布局工作。
3. **亮色角标描边 2.35:1**——需在可访问性打磨中增设 `on-warning` 前景令牌。
4. **`GoBack` 纯栈语义**——从路由进入的空状态无法经返回键离开。
5. `Routes.Find` 新增一个"可导航但不入 `All`"的路由需改两处，建议引入 `Routes.Registered` 聚合。

### 归入 P6

- spec §5.4 提到的"菜单未读徽标"**没有任何阶段认领**——归 P6（未读徽标由告警驱动，与监控推送同源）。
